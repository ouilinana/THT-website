# FR / EN language plan

## Implemented in this PR

- French pages at `/`, `/cherche-en-corps`, `/fleur`, etc. (extensionless URLs via Caddy).
- English pages under `/en/` with matching paths.
- `<html lang="fr|en">`, `hreflang` alternates, and header links `[fr/en]` between locales.
- No JavaScript language toggle; content is fully server-rendered HTML.

## Future options

1. **Keep static dual pages** (current): edit FR and EN blocks in `scripts/build_site.py` post-processing or split shared partials if the design toolchain returns.
2. **Eleventy or similar**: migrate body copy to Markdown/JSON with a single layout template.
3. **Subdomain** `en.trois-heures-trente.com` if marketing prefers separate origins (update `hreflang` and canonicals accordingly).
